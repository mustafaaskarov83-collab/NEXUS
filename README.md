# NEXUS ENGENEERING — HR / ERP портал

Корпоративна система «в одному вікні»: кадровий облік, інвентар, документообіг, фінанси, задачі та KPI-аналітика.

- **Live (GitHub Pages):** https://mustafaaskarov83-collab.github.io/nexus-hr-system/
- **Репозиторій:** https://github.com/mustafaaskarov83-collab/nexus-hr-system
- **Технології:** HTML5 + CSS3 + Vanilla JavaScript, дані — `localStorage`, Excel — SheetJS (CDN), графіки — Chart.js (CDN)
- **Версія проєкту:** 5.0.0 — системне ядро: `nexus-core.js`

## Як запустити

1. Відкрийте `index.html` у браузері (або Live-посилання) — це головна сторінка порталу.
2. Головна сторінка відкривається першою. Для переходу в захищений модуль натисніть його картку; якщо потрібно, система запропонує увійти через `hr.html`.
3. Після входу система повертає вас до модуля, який ви відкривали.

Вкладки HR можна відкривати напряму через хеш: `hr.html#employees`, `hr.html#calendar`, `hr.html#calc`, `hr.html#settings`.

## Ролі

| Роль | Права в HR | Права в модулях |
|---|---|---|
| `admin` | усе, включно з користувачами та реквізитами компанії | усе |
| `manager` | перегляд + редагування (без «Налаштувань») | усе (read + write) |
| `viewer` | тільки перегляд | тільки перегляд у всіх модулях (`canEdit` + глобальний `enforceReadOnly`) |

## Дані та бекапи

- Ключі `localStorage`: `nexus_users_v1`, `nexus_session_v1`, `nexus_hr_ua_v2`, `nexus_inventory_v1`, `nexus_documents_v1`, `nexus_finance_v1`, `nexus_tasks_v1`, `nexus_projects_v1`, `nexus_theme_v1`, `nexus_audit_v1`, `nexus_notifications_v1`.
- Бекап: у кожному модулі → «Експорт JSON»; глобальний backup усіх ключів — **Ctrl+Shift+B**.
- Сесія діє 12 годин, далі потрібен повторний вхід.

## NEXUS Core v5

Нова версія додає спільне клієнтське ядро `nexus-core.js`: єдиний контроль сесії та RBAC-дозволів, аудит дій, системні повідомлення, глобальний резервний backup/restore, обробку runtime-помилок і автоматичний режим read-only для ролі `viewer`.

Глобальний backup усіх ключів NEXUS можна створити клавішами **Ctrl+Shift+B** на будь-якому модулі.

> Важливо: поточний реліз залишається offline-first на `localStorage`. Це покращує структуру і контроль клиента, але не превращает браузерное хранение данных в серверную многопользовательскую безопасность. Для production-сервера следующий этап — FastAPI + PostgreSQL + server-side authentication.

## Обмеження (важливо знати)

- `localStorage` окремий для кожного браузера й пристрою — синхронізації між пристроями немає.
- Авторизація клієнтська (пароль + сіль зберігаються в `localStorage`) — це захист «від випадкового ока», а не справжня безпека.
- Excel і графіки мають локальні копії в `vendor/` з fallback на CDN.
- Роль `viewer` блокується і на рівні модуля (`canEdit`), і глобально через `NexusCore.enforceReadOnly`.
