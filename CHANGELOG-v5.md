# NEXUS ENGENEERING 5.0.0

## Что изменено
- Добавлен общий `nexus-core.js` для всех рабочих модулей.
- Единая версия приложения 5.0.0.
- Добавлен централизованный RBAC-слой с разрешениями для admin/manager/viewer.
- Добавлен аудит системных событий и ошибок.
- Добавлены системные уведомления/toast.
- Добавлен глобальный backup всех ключей NEXUS через Ctrl+Shift+B.
- Добавлен импорт полного backup через API `NexusCore.importAll(file)` для дальнейшего подключения к UI.
- Для роли viewer автоматически включается read-only режим во всех модулях, включая динамически создаваемые кнопки.
- Добавлена глобальная обработка JavaScript-ошибок и unhandled promise rejection.
- Добавлены общие helper-функции безопасного чтения/записи localStorage.
- Обновлена документация проекта.

## Важное ограничение
Релиз остаётся offline-first и использует localStorage. Это не заменяет серверную авторизацию и многопользовательскую БД. Для production-режима следующий архитектурный этап — FastAPI + PostgreSQL + server-side sessions/RBAC.

## 5.0.1 — Проекти
- Додано центральний модуль `projects.html/js/css`.
- Додано єдиний довідник проектів з кодом, назвою, замовником, керівником, статусом, періодом та плановою сумою.
- Проект пов'язується з договорами/документами, інвентарем, співробітниками, задачами та фінансовими операціями.
- У картці проекту автоматично рахуються персонал, інвентар, договори, документи, задачі та фінансовий рух.
- Для договорів автоматично визначається кількість та загальна сума пов'язаних договорів.
- Видалення проекту з пов'язаними даними заблоковано для захисту зв'язків.
- Додано вибір проекту при створенні/редагуванні документа, інвентарю, задачі та фінансової операції.
- Додано прив'язку співробітників до одного або декількох проектів.
